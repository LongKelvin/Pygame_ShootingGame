# Shoot 'em Up

**Shoot 'em Up** is a simple Python Pygame project.

## Installation

To get started, you'll need Python and Pygame:

- [Python](https://www.python.org/downloads/)
- [Pygame](https://www.pygame.org/wiki/GettingStarted)

Install Pygame using pip:

```bash
pip install pygame
```

After installing the dependencies, clone or download the project as a ZIP file, then run `main.py`:

```bash
python main.py
```

Alternatively, you can download `shooting_launcher.exe` from the release package and execute it.

## How to Play

This game is very simple to play:

- `W` or `UP` arrow key to move forward
- `S` or `DOWN` arrow key to move backward
- `A` or `LEFT` arrow key to turn left
- `D` or `RIGHT` arrow key to turn right
- `SPACE` to fire
- `P` to pause
- `ESC` to exit

The more enemies you shoot, the higher your score.
